# 验证策略方向修正记录（2026-08-02）

## 1. 结论

**停止把「LLM 重新解题」当作题目入库/放行的门禁。** 数学验证从"必需门禁"降级为"可选的质量异常信号"。

项目第一优先改为：**证明可信源文件进入数据库的过程没有损耗（保真度审计）**。

## 2. 为什么之前的方向是错的

<local-scratch>的前提是：来源可信、可直接给学生使用、题目与答案以源文件为准。在这个前提下重新用 LLM 解题验证，会产生四类问题，且在 MATH-VALIDATION-003/004/005 中全部实际出现：

1. **模型算对、答案表达不同 → 误判 fail。** 003 的 17 个 fail 中约 9 个属此类；005 复核 50 条中 2 条不一致同样是语义等价比对缺口。
2. **提取损耗被误记为题目缺陷。** 005 中 220 个 unsupported、003 中 35 个 unsupported 的真实原因是题干公式/条件/表格碎片缺失——这是**导入损耗**，不是题目错误，却被记成了题目的验证状态。
3. **模型自身可能出错，反而阻断可信题目**，或产生假阳性放行。004 实测到 `gpt-5.4-mini` 对表格缺失题凭规律猜中源答案判 pass（人工期望 unsupported）。
4. **持续消耗 API 却没解决核心问题**：源文件到数据库到底有没有丢内容，这个问题一次也没有被回答。

## 3. 真正需要验证的是"保真度"

应验证数据是否与源文件一致，而不是重新验证数学答案。保真维度：

1. 源文件题目数量与数据库题目数量一致；
2. 题干文字完整（无截断、无碎片）；
3. 公式、特殊符号、上下标未丢失；
4. 图片、表格、图形正确绑定到对应题目；
5. 选项顺序、选项文字、答案顺序未改变；
6. 答案与解析完整；
7. 每道题可追溯回原始文件、原始段落、原始资源；
8. 数据库回渲染输出的内容与源文件一致。

技术手段：Word COM 原文读取、文档 XML/媒体资源检查、文本/公式/图片/表格的数量与哈希比对、数据库回渲染比对、必要时人工抽样查看。**不使用 LLM 解题作为入库门禁。**

## 4. API 的正确位置：生成阶段

API 用于讲义等交付文件的生成阶段：

- 按知识点、班级进度、难度筛选题目；
- 组织讲义结构；
- 生成讲解文字、教学提示、知识总结；
- 检查生成后的讲义是否存在明显内容冲突；
- 辅助处理复杂教学表达。

**边界：API 不得改写或替代可信源题目的原文、公式、选项、答案和图片。** 题目正文一律从数据库原样取出；确需改写的必须显式标记为"改编题"，不得继续冒充源题。

## 5. 题目可用于讲义的新资格逻辑

判定依据改为：

- 来源可信；
- 导入完整（保真度通过）；
- 结构化成功；
- 公式与图片完整；
- 知识点映射通过；
- 难度证据存在；
- 符合当前班级课程范围；
- 满足复用与交付历史规则。

数学验证的新定位：非必需门禁；可作为可选异常检测；发现异常时转人工检查；**不得因为 LLM 无法重新解出题目就否定可信源题目**。

## 6. 对既有成果的处置

| MATH-VALIDATION-001（只读审计） | 保留。其 reason 分布是**导入损耗的间接证据**，对保真度审计有价值（如 1,051 figure_required、879 form_unsupported）。 |
| MATH-VALIDATION-002（确定性验证器） | 代码保留、不删除。64 条 pass 仅作可选质量信号，**不作为放行依据**。 |

| MATH-VALIDATION-005（全量 LLM 验证） | **终止，不续跑剩余 533 道，不充值、不更换密钥继续。** 已完成 474 道结果归档为实验记录，**不写入正式数据库、不作放行条件**。 |
| 未来 MATH-VALIDATION-006（证据写库 + LFS 重发布） | **取消。** 不把 LLM 验证状态写入正式库作为门禁。 |

累计 LLM 试点花费：约 ¥15.23（004）+ ¥1.31（005）+ 003 试点（按次计费口径约 ¥54）。这些支出换来的有效结论是：**大量 unsupported 的根因是导入损耗**，这直接推导出保真度审计的必要性。

## 7. 新路线图

- **阶段 1（当前最高优先）保真度审计**：FIDELITY-001 基线与维度定义 → 002 数量与顺序 → 003 公式与符号 → 004 图片与表格绑定 → 005 回渲染一致性。
- **阶段 2 资格模型改造**：ELIGIBILITY-001，资格视图改以保真 + 知识点 + 难度 + 课程范围为依据，数学验证降级为可选信号。
- **阶段 3 生成期检查**：GEN-001，明确生成阶段 API 职责与"原文不改写"边界。
